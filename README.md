# Nova — web/PWA demo

Мобильный демонстрационный интерфейс мессенджера Nova.

## Что уже работает
- адаптивный интерфейс для iPhone;
- разделы «Все», «Личные», «Группы», «Каналы»;
- поиск по чатам;
- создание локального демо-чата;
- отправка тестовых сообщений;
- сохранение демонстрационных чатов в localStorage;
- PWA-манифест и service worker для установки на экран «Домой».

## Важно
Это пока **не настоящий сетевой мессенджер**. Демо-сообщения доступны только в браузере на этом устройстве. Регистрация, серверная синхронизация, фото/видео, голосовые сообщения, звонки, настоящие группы и каналы ещё не подключены.

## Публикация через GitHub Pages
1. Распакуйте архив.
2. Загрузите `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg` в корень репозитория.
3. В GitHub откройте Settings → Pages и выберите Deploy from a branch / main / root, если используете классическую публикацию. Либо добавьте workflow GitHub Actions.
4. После публикации откройте адрес Pages в Safari на iPhone.
5. Нажмите «Поделиться» → «На экран Домой».

Для публикации через workflow добавьте файл `.github/workflows/pages.yml` с содержимым из `pages.yml.example`.

## Дальнейшая разработка
Следующий этап — сервер Node.js, база PostgreSQL, авторизация, Socket.IO и хранение медиа. Для постоянной работы потребуется размещённый сервер и безопасная конфигурация.
